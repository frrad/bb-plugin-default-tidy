Default Tidy keeps BB’s default light and dark colors while making the sidebar easier to scan.

## Layout

Larger section headings, indented threads, and tighter section spacing give each group a clearer shape. The top New thread button is hidden; each group’s New thread action stays available. Expanded section headings hide their collapse toggle, while collapsed sections keep a toggle so they can be reopened.

## Dividers

Name an empty custom section with a leading `- ` to display it as an uppercase divider label with a hairline. Divider bodies are hidden, so keep these sections empty.

## Activation

After installing, select Default Tidy in Settings → Appearance or run `bb theme set plugin:default-tidy:default-tidy`. Switch to another theme to remove the changes. Requires BB 0.48 or later with a compatible Plugin SDK. No external service or account is required.

The layout uses BB’s internal DOM selectors and may require updates when BB changes its sidebar markup.
